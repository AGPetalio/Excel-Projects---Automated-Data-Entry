# Sample of databases I made with Automated Data Entry using Macro
# My first ever set of databases created using Excel, with capability for data entry, and visualizations thru pivot tables and graphs.

1.URCF FLOURMILL PLANT PMD #
  This includes following:
    INPUT PAGE - actual input of data (mostly related to products, production dates, weights, and dispositions)
    DATABASE PAGE - Tab with editable parts which will reflect on the RECALL page
    SUMMARY PAGE - Tab with independent records of data encoded (This is independent from DATABASE PAGE), and is can be used     as raw data for further analysis and visualizations.
    RECALL PAGE - Tab where data encoded in the DATABASE PAGE may be recalled by using Primary Key
    *This is macro-enabled for automated data entry to DATABASE PAGE and SUMMARY PAGE.

2.URCFQA Database 2026
   This includes following:
     RAW DATA PAGE - Tab where results can be input
     SUMMARY PAGES (Milling, Packing, Wheat Tempering) - Serve as separated tabs as destination to input data from RAW DATA       PAGES. These pages can be used for further analysis and visualization (see URCF Flour Trends Pasig).
    *This is macro-enabled for automated data entry to SUMMARY PAGES.

3.URCF Flour Trends Pasig
  This includes following:
    RAW DATA PAGE - Tab which contains tables to encode records
    OTHER TABS - Contained Tabs with customized data trends by showing minimum, mean and maximum data on each selected             parameters per production date.
